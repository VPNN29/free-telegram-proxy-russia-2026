<h2>❓ Частые вопросы</h2>

<p><strong>Это бесплатно?</strong> Да. Прокси из таблицы бесплатны и без регистрации. Некоторые публичные прокси показывают закреплённый канал своего владельца — это нормально, его можно закрыть.</p>

<p><strong>Почему прокси перестал работать?</strong> Роскомнадзор блокирует прокси-адреса по одному, обычно на несколько часов или дней. Поэтому список здесь обновляется каждые 2 часа.</p>

<p><strong>Как проверяются прокси?</strong> С российского сервера каждые 15 минут: реальное подключение по протоколу MTProto, как это делает Telegram, FakeTLS-прокси — тем же самым, что в приложении Telegram (TDLib). В таблице только прокси, к которым подключение подтверждено. Пинг — задержка от российского сервера до прокси.</p>

<p><strong>Работает на МТС, МегаФоне, Теле2, Билайне, Yota?</strong> Да, проверка идёт из российской сети. Но если оператор включает белые списки (отключение местного интернета), не работает ни один прокси — нужен VPN, см. раздел выше.</p>

<p><strong>Прокси или VPN — что лучше для Telegram?</strong> Прокси включается и настраивается в один инструмент, но работает только внутри Telegram. VPN защищает весь телефон и проходит через белые списки. Для Telegram обычно хватает прокси; если его режут — VPN.</p>

<p><strong>Безопасно ли это? Прокси видит мои сообщения?</strong> Нет. Telegram шифрует переписку до того, как она попадает в прокси, поэтому владелец прокси видит только зашифрованный трафик.</p>

<p><strong>Прокси для iPhone работает?</strong> Да, MTProto-прокси работает в Telegram для iOS. WEB-прокси работает в Telegram Desktop и в Telegram для Android 12.10.4+ (экспериментально), на iPhone его пока нет.</p>

<p><strong>Телеграм тоже на компьютере?</strong> Да: MTProto из таблицы или новый WEB-прокси, его сложнее заблокировать.</p>

<h2>📱 Как подключить прокси в Telegram</h2>

<p><strong>Андроид и Айфон.</strong> Нажми ⚡ Подключить в таблице → Telegram откроется сам → «Подключить прокси». Значок щита вверху экрана станет синим.</p>

<p><strong>Компьютер (Windows, macOS, Linux).</strong> Нажми ⚡ Подключить в браузере → предложит открыть Telegram Desktop → «Включить».</p>

<p><strong>Вручную.</strong> Настройки → Данные и память (на ПК: Продвинутые → Тип соединения) → Прокси → Добавить прокси → MTProto → впиши сервер, порт и секрет из списка.</p>

<p>Можно добавить сразу несколько прокси: Telegram сам переключится на тот, что работает.</p>
